Deployment path

From purchase to live door in four steps.

You keep the client relationship and the installation. We provide the software, commissioning support, and a written deployment record.

Scope the site

Count doors, cameras, and kiosk locations. Confirm Axis controller model, relay wiring, fail-safe strike, REX, and fire release.

Install the node

Install the Windows app, enroll identities, bind the kiosk door, add RTSP streams, and connect the optional LAN hub.

Prove the policy

Test an authorized role, an unauthorized role, a closed schedule, and a disconnected controller. Everything must fail closed.

Hand off the audit

Export the deployment report, verify the audit trail, and leave a documented backup and recovery procedure.

Built for the field

Designed to survive a real site, not a demo table.

Windows kiosk, PoE cameras, and an Axis controller. No cloud account is required for verification, door decisions, or audit capture.

  • Offline-first. Local templates, local rules, local audit. The hub is optional and recoverable.
  • Fail closed. Missing schedule, controller error, or policy denial never opens the strike.
  • Tray mode. Closing the window keeps camera processing alive; quit explicitly to stop it.
  • Field exports. CSV audit history and a printable technical spec sheet for the client file.
