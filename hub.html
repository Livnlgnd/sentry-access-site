Hub & licensing

A site-owned control plane with a commercial layer that scales.

The hub distributes identities, consolidates audit, pairs iPhones, and stores backups. Licensing controls capacity offline, and annual support enables signed in-app updates.

LAN hubSigned bundlesPerpetual licenseSigned updates

LAN hub

  • Fastify API and PostgreSQL on the customer network.
  • Device registration with site-scoped tokens.
  • ECDSA-signed identity bundles and delta sync.
  • Audit ingestion and mobile pairing codes.
  • mDNS discovery and a stable hub ID.
  • Backups containing the database, keys, license, and enrollment secret.

Offline enforcement

Licenses are ECDSA P-256 signed files verified locally. The hub enforces kiosk and mobile-seat limits; the kiosk enforces door and camera-stream limits. Dropping in a new license upgrades capacity without reinstalling.

Signed updates

The desktop updater verifies a signed manifest and SHA-256 installer, and only checks while the license has an active support date. Core verification, doors, and audit keep working if support lapses; only updates are blocked.

Limits: the hub is single-node with no HA/failover, central SSO, remote session revocation, or per-event device signatures yet. The Windows installer is unsigned until Azure Trusted Signing is active.
