Five surfaces, one deployment

The platform is deliberately split so each part can run where it belongs: the kiosk owns the biometric decision, the door controller owns the relay, the camera gateway owns the RTSP decode, and the hub owns distribution and history. If the hub is offline, verification and door policy keep working.

Deployment modes

Single kiosk: Windows app, local door controller, local audit, and optional cameras. No hub required.

LAN site: add the PostgreSQL hub for identity distribution, audit consolidation, backups, and local mobile-free access.

Multi-site: run one hub per site and use signed licenses to scope capacity and annual support.

Positioning: this is a local-first product for integrators, not a cloud video platform. It does not claim UL/EN/SOC 2 certification or life-safety suitability.
